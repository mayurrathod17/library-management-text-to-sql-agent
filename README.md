# Library Management Text-to-SQL Agent

## Project Overview
The Library Management Text-to-SQL Agent is an AI-based application that allows users to retrieve library information by asking questions in natural language.

The application converts English questions into SQL queries and displays the results from a library database.

## Technologies Used
- Python
- Google Gemini AI
- SQLite
- Gradio
- Pandas
- Google Colab

## Features
- Book availability search
- Overdue book retrieval
- Student borrowing history
- Natural language to SQL conversion
- Interactive web interface
- SQL query preview and results

## Database
The project uses three tables:
1. Books
2. Students
3. Borrowing

The sample dataset is generated using Python.

## How to Run
1. Open the `.ipynb` notebook in Google Colab.
2. Install the required libraries.
3. Add your Gemini API key through Colab Secrets.
4. Run all notebook cells.
5. Open the generated Gradio application link.

## Project Objective
To make database querying easier by allowing users to ask questions in simple English instead of writing SQL manually.
